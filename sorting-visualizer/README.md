# 排序實驗室 · Sorting Lab

Homework 9 的排序演算法視覺化作業。可以用同一組資料比較氣泡排序、選擇排序、插入排序和快速排序，逐步查看比較、交換、定位與操作次數。

用瀏覽器直接開啟 [docs/index.html](docs/index.html) 就能使用。網站可離線運作，不需安裝套件。
